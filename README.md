# 🏥 Hospital Management System

### A Smarter Way to Manage Hospital Operations

A web-based Hospital Management System designed to simplify and organize essential hospital activities, including patient records, doctor information, appointments, and pharmacy management.

The goal of this project is to make hospital operations more organized, accessible, and efficient through a centralized digital platform.

---

## ✨ Key Features

- 👨‍⚕️ **Doctor Management** — Organize and manage doctor information and specialties.
- 🧑‍🤝‍🧑 **Patient Management** — Maintain and access patient records.
- 📅 **Appointment Management** — Simplify the organization of doctor appointments.
- 💊 **Pharmacy Management** — Manage pharmacy-related information.
- 🩺 **Specialty Corner** — Organize information about medical specialties.
- 🌐 **Web-Based Interface** — Access hospital management features through a web application.
- 🔗 **Frontend–Backend Integration** — Connect the user interface with backend functionality.

---

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JAVASCRIPT 
- **Backend:** Node.js, Javascript
- **Database:** MySQL
- **Development Tools:** Visual Studio Code, Git, and GitHub.
- **API** Custom-built API's developed for hospital management system

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/paridhi-vaidya/Hospital-Management-System.git
```

### 2. Open the project

```bash
cd Hospital-Management-System
```

### 3. Install dependencies

Open a terminal in the relevant project directory and run:

```bash
npm install
```

Repeat this for the frontend or backend if either has its own `package.json`.

### 4. Configure the project

Set up the required environment variables and database connection according to your project's configuration. Keep credentials and secret keys private.

### 5. Run the application

Use the start command defined in the relevant `package.json`. For example:

```bash
npm start
```

The exact commands may differ depending on your project's configuration.
